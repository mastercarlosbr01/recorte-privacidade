# Política de privacidade do Recorte

Página pública exigida pela Chrome Web Store, servida pelo GitHub Pages:

**https://mastercarlosbr01.github.io/recorte-privacidade/**

É um repositório separado de propósito. A página precisa continuar no ar
enquanto a extensão estiver publicada, independentemente do que aconteça com o
código — e o histórico de alterações de uma política de privacidade deve ser
verificável por quem a leu antes.

## O que ela declara

Que a extensão não coleta, não armazena e não transmite dado algum.

A declaração não é pedida por confiança: a página aponta para
[o código-fonte](https://github.com/mastercarlosbr01/recorte), que tem uma
auditoria automática reprovando a compilação se alguém escrever uma chamada de
rede, execução dinâmica de código ou URL remota.

## Se mudar

Atualize a data no topo do `index.html` junto com o texto. O histórico do git
é o registro de quando cada versão valeu.
